# Provenance: reverse-engineer-anything

- **Type:** native, original method. No third-party text is copied into this skill.
- **Inspiration lineage:** REA (Reverse Engineer Anything). Canonical upstream is [morluto/rea](https://github.com/morluto/rea) (MIT, © 2026 morluto), inspected at commit `9e24b36fa69423098627309cb61f8bbf1d23d3f8` (main, 2026-11-14). The ecosystem is fragmented: name-clone repos (`NabilRFG12/Reverse-Engineer-anything`), compressed no-MCP rewrites (`aicodeking/leanrea`), prompt packs (`JoasASantos/REA-Prompts`), awesome lists, and a defensive counter-skill (`davepartner/anti-reverse-engineer-anything`). Every clone's own README points back to morluto/rea, rea.tools, and the `rea-agents` npm package as the official sources, and its skill file (`.agents/skills/reverse-engineer-anything/SKILL.md` at the pinned commit) is a real method, not a demo app. Note: the widely cited `davepartner/reverse-engineer-anything` repo no longer exists; the assumed original lineage was wrong and morluto/rea is canonical.
- **License:** upstream is MIT. This skill is inspired-by, not vendored: our method, structure, and wording are original (Apache-2.0, this repo), so no upstream license file is bundled and no MIT notice obligation is triggered by copied text—the MIT notice here credits the inspiration lineage instead.
- **What upstream does that we do not:** REA ships an MCP server (207 tools), analysis engines (Ghidra, JADX, Binwalk, Frida bridges), and a setup/doctor lifecycle. Our skill assumes only the tools an agent already has (`strings`, `grep`, `sha256`, capture tools) and encodes the investigation method, not a toolchain.
- **Departures from upstream:** complete. The five-phase method (scope, map surface, capture, trace, teardown doc) formalizes our own recurring passes (company DD pages, agent-harness audits, capture-to-vault round-trips, console recon); the layer discipline (observed/inferred/claimed) and the coverage-statement requirement are ours.
- **Relationship:** `auditing-agent-harnesses` (deep privacy verdicts on one target class), `security-audit` (source-level vulns), `live-system-forensics` (machine-level). This skill owns the product/mechanism teardown.
- **Refresh:** none needed while the skill stays original. If we ever vendor upstream text, pin the commit here and repeat the full vetting pass from `skills/README.md`.
