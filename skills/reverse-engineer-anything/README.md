# reverse-engineer-anything

Teardown method for products, apps, agent harnesses, and protocols you cannot read as source. Five phases—scope, map the surface, capture, trace, teardown doc—with a three-layer evidence discipline (observed / inferred / claimed) and a required coverage statement.

Inspired by the REA ecosystem; original method, no MCP server or toolchain needed. Details in [PROVENANCE.md](PROVENANCE.md).
