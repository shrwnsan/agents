# Crash Logs and Diagnostic Reports

Crash reports and diagnostic logs generated by macOS and applications when errors occur.

## Directories

| Location | Description | Cleanability |
|----------|-------------|--------------|
| `~/Library/Logs/DiagnosticReports/` | macOS user crash reports | Inspect first |
| `/Library/Logs/DiagnosticReports/` | macOS system crash reports | Inspect first |
| `~/.local/state/*/crash/` | App-specific crash dumps | Safe |
| `~/Library/Application Support/*/logs/` | App logs (catch-all) | Inspect first |

## Scanning Commands

```bash
# User crash reports
du -sh ~/Library/Logs/DiagnosticReports/ 2>/dev/null
ls -lt ~/Library/Logs/DiagnosticReports/ | head -20

# System crash reports (may require sudo)
du -sh /Library/Logs/DiagnosticReports/ 2>/dev/null

# App-specific crash directories
find ~/.local/state -type d -name "crash" 2>/dev/null
du -sh ~/.local/state/*/crash/ 2>/dev/null

# App logs directories
find ~/Library/Application\ Support -type d -name "logs" 2>/dev/null
du -sh ~/Library/Application\ Support/*/logs/ 2>/dev/null

# Count crash files (including .spin for spindump)
find ~/Library/Logs/DiagnosticReports/ \( -name "*.ips" -o -name "*.crash" -o -name "*.spin" \) 2>/dev/null | wc -l
```

## Notes

### ~/Library/Logs/DiagnosticReports/
- macOS automatically generates these when apps crash
- Files are in JSON (.ips), text (.crash), or spindump (.spin) format
- Useful for debugging but safe to delete
- Contains app name, crash reason, and stack traces

### ~/.local/state/*/crash/ (App-specific crash dumps)
- Apps using Sentry or similar crash reporters
- Often in proprietary formats
- Safe to delete - already submitted to crash reporting service

### ~/Library/Application Support/*/logs/ (App logs)
- Known apps: VS Code, Cursor, Windsurf, Kiro, Slack, Discord, Antigravity
- Use file-based cleanup, not directory deletion
- Prefer age-based deletion (30+ days)

## Safety Safeguards

When scanning `*/logs/` glob patterns:

1. **Directory name validation** - Only target directories named exactly `logs/`
2. **Contents inspection** - List contents before deletion; skip if contains state/config/settings files
3. **File-based cleanup** - Prefer: `find ~/Library/Application\ Support/*/logs/ -name "*.log" -mtime +30`
4. **Age-based deletion** - Default to files older than 30 days for app logs

## Typical Sizes

- User crash reports: 50 MB - 2 GB (depends on usage)
- System crash reports: 10 MB - 500 MB
- App-specific: 10 MB - 100 MB per app
