# Memory Index

Tool-operation knowledge for agents working in this repo, in Open Knowledge
Format (OKF) v0.1 ([spec](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)).
One Markdown concept per file with a `type` frontmatter line; `index.md` (this
file) and `system/definition.md` are the reserved entry points.

## Map

- [tools/](tools/agentmail-rest.md) — operating notes for specific APIs and
  services, starting with [AgentMail REST](tools/agentmail-rest.md)
- [system/](system/definition.md) — how this bundle works

Files here are reference, not skills: nothing auto-loads them. An agent doing
work in the covered area should read the relevant file first.
